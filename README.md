# ESP32 Tutorials

Welcome to the **ESP32 Tutorials Repository**
This repository contains beginner to advanced ESP32 projects, examples, and tutorials using Arduino IDE or PlatformIO.
I post tutorials and project videos on Instagram and YouTube, and all the source code used in those videos will be available in this repository.

---

## About

This repo is created to help learners understand and build projects with the ESP32 microcontroller.

Topics included:
- WiFi Projects
- Web Servers
- Captive Portals
- Sensors & IoT
- Bluetooth
- OLED Displays
- MQTT
- Home Automation
- ESP32 with APIs
- and more...
---

## 🛠 Requirements

Before uploading or running the code, install:

- Arduino IDE or PlatformIO (Recommended)
- ESP32 Board Package
- Required Libraries (based on projects)
